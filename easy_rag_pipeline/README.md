# Easy RAG Pipeline

**A reusable and configurable RAG (Retrieval-Augmented Generation) pipeline built in Python.**

This library provides a production-grade, easy-to-use framework for building and deploying RAG applications. It allows you to plug in different LLMs, embedding models, and vector stores with a simple, configuration-driven setup.

## Features

- **Pluggable Components**: Easily switch between LLMs (**OpenAI, Groq, Gemini, OpenRouter**), embedding models (OpenAI, HuggingFace), and vector stores (FAISS).
- **Configuration Driven**: Manage all your settings through a single `config.yaml` file.
- **Clear Structure**: A modular and extensible codebase that separates concerns like ingestion, embedding, and generation.
- **Example Implementations**: Includes a basic command-line example and a Streamlit UI demo to get you started quickly.

## Installation

1.  **Clone the repository:**
    ```bash
    git clone <repository-url>
    cd easy_rag_pipeline
    ```

2.  **Create a virtual environment (recommended):**
    ```bash
    python -m venv venv
    source venv/bin/activate  # On Windows, use `venv\Scripts\activate`
    ```

3.  **Install the dependencies:**
    ```bash
    pip install -r requirements.txt
    ```

4.  **Install the package in editable mode:**
    This allows you to modify the source code and have the changes immediately reflected.
    ```bash
    pip install -e .
    ```

## Quick Start

1.  **Set up your API keys:**
    Copy the `.env.example` file to a new file named `.env`.
    ```bash
    cp .env.example .env
    ```
    Open the `.env` file and add the API key for the LLM provider you wish to use (e.g., OpenAI, Groq, etc.).
    ```
    # For OpenAI
    OPENAI_API_KEY="sk-..."

    # For Groq
    GROQ_API_KEY="gsk_..."

    # For Google Gemini
    GOOGLE_API_KEY="AIzaSy..."

    # For OpenRouter
    OPENROUTER_API_KEY="sk-or-..."
    ```

2.  **Configure your LLM:**
    Open `examples/config.yaml` and choose the LLM provider and model you want to use. The file contains commented-out examples for each supported provider. For instance, to use Groq:
    ```yaml
    llm:
      provider: "groq"
      model: "llama3-8b-8192"
      temperature: 0.7
    ```

3.  **Run the basic example:**
    This script will ingest the `sample_document.txt`, ask a question about it, and print the answer generated by your configured RAG pipeline.
    ```bash
    python examples/basic_rag.py
    ```

    You should see output similar to this:
    ```
    Question: What is Retrieval-Augmented Generation (RAG)?
    Answer: Retrieval-Augmented Generation (RAG) is a technique that enhances the accuracy and reliability of Large Language Models (LLMs) by grounding them on external knowledge sources. It involves retrieving relevant documents based on a query and using them as context for the LLM to generate a more informed answer.
    ```

## Running the Streamlit Demo

This package includes a simple web-based UI demo built with Streamlit.

1.  **Ensure you have completed the installation and setup steps above.**

2.  **Run the Streamlit app:**
    ```bash
    streamlit run examples/streamlit_demo.py
    ```
    This will open a new tab in your browser with the demo application. You can enter a query in the text box and get an answer from the RAG pipeline.
